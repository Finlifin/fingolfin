# 模式参考求值语义

`src/pattern.rs` 是无副作用参考求值器，用于与优化门控进行差分验证。输入为已经符合已检查模型类型的对象快照，输出为绑定行和 incomplete 标记；目前不读取原始模型指针，也不执行入口主体。

- 普通对象字段合取、嵌套 record、半开/闭区间、字面量和绑定均直接读取本次快照。
- OR 是绑定行的集合并集：相同名称和值的行去重，不同值的行保留。无绑定的两个真分支只产生一个空行；两个分支分别绑定 x=1、x=2 则产生两行。
- NOT 只判断是否存在匹配，永不导出子模式绑定。
- 缺少字段或显式 Unknown 产生未知，不等同于 false。false AND unknown 为 false；NOT unknown 仍未知。OR 可同时返回已证明的匹配和 incomplete，表示部分分支尚不能确定。
- 字段类型与模式不相容、重复绑定是显式错误。未知 wildcard 当前仍标为 incomplete，即便该值没有被输出。
- 每次求值有步数预算，节点、字段匹配和绑定合并都扣预算；耗尽明确报错，不静默丢行。

参考对象关系为单值嵌套 record。tt-emule 的 C provider 已支持身份属性与对象生命周期，见 [模型属性阶段](../model-availability.md)；多值关系、可变采样和有状态属性维护仍在当前范围之外。
