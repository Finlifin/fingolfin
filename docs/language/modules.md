# 当前模块与类型检查规则

文件模块规则见 README。声明收集完成后，导入采用固定点迭代，允许引用扫描顺序较后的声明和再导出。没有实际声明作为来源的再导出环报错。

`use a.B` 把 `B` 引入本模块，`pub use a.B` 还允许其他模块从本模块访问这个别名。别名保留原声明的符号身份。声明、导入别名重名报错；hook/object 的完整逻辑路径跨文件重复也报错。

路径以当前包名开头时为包根绝对路径。其他路径先按当前模块相对路径查找，再按包根路径查找；已经存在但尚未解析的相对别名不能误回退到根模块中的同名类型。跨模块只能访问 public 声明或 public 再导出，private 名字只对所属模块可见。此规则是 Fingolfin 当前独立定义，不宣称复现 Luna 的全部可见性规则。

符号身份使用 `包名::模块.声明名`，不依赖扫描序号或机器上的绝对路径。该身份仅适用于当前锁定依赖集合；未来产物兼容性还须结合包版本和模型 fingerprint，不能单独用这个字符串作为 ABI 兼容性保证。

目前依赖闭包包含实际导入的声明模块和再导出模块。它只提供失效集合计算，尚不构成编译缓存；直接全限定类型引用、函数调用、属性依赖的追踪仍待补齐。

类型检查当前固定为 Linux x86-64 小端 ABI profile：u/i8、16、32、64，1 字节 bool，8 字节指针，固定数组、struct 和明确整数表示的 enum。结构体按声明顺序布局并补齐字段及尾部对齐，拒绝空 struct、零长数组、超出目标对象大小的布局和按值递归；指针递归允许。enum 判别值必须唯一并能被底层整数表示。

`inspect --types` 校验参数数量、顺序和规范类型（包括指针与按值区别），但它尚不是完整的程序语义检查或跨语言 ABI 调用证明。`inspect --bodies` 已加入函数体和固定布局 where 模式检查；模型的精确属性阶段契约也会检查，具体稳定性和失效通知仍由模型实现保证，见 [属性阶段](../model-availability.md)。
