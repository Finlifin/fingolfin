# 语法来源与差异

设计来源版本沿用项目计划：Luna `44bf45ec66c8b249a4eb3e016e965b119a60ed2f`。本仓库语法和 AST 实现为独立编写，未复制 Luna 源码；此处记录语言设计溯源，不宣称与 Luna 源语言兼容。

| 构造 | 来源与范围 | Fingolfin 当前定义 |
|---|---|---|
| fn/struct/enum、点路径、use/pub、let/var、-- 注释 | 项目计划借鉴 Luna 的表面风格 | 由本仓库 pest grammar 定义受限子集 |
| on/where | Fingolfin 扩展 | on 指定逻辑 hook 路径；where 只允许用于入口 |
| hook/object 声明 | Fingolfin 原创模型语法 | hook 声明参数；object 声明逻辑路径和字段；元数据语法待后续扩展 |
| enum 表示 | C ABI 设计约束 | 必须写整数底层类型及每个变体的显式值；已检查整数表示、判别值范围和重复值 |
| range/or/as/not | 观测模式语法 | 半开/闭区间；绑定；对象模式析取与否定；空/反向区间当前直接诊断 |
| 导入与模块 | 项目计划中的文件模块设计 | 已实现文件发现、声明收集、导入及再导出；实际跨包依赖锁定仍待实现 |

整数解析暂以 i128 表示，最终 ABI 整数宽度由语义阶段限制。浮点、泛型、trait、comptime、裸内存写入和无界循环未纳入当前语法。所有尚未实现的计划能力均保留在开发记录中，不因当前 parser 子集而取消。
