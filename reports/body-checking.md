# 函数体与模式检查验证

2026-11-01，当前工作树未提交。新增 `src/sema.rs` 与 `inspect --bodies`，不代表运行时或完整 v0.1 已完成。

覆盖：局部作用域、let/var、参数不可写、声明类型和字面量范围、函数参数/返回值、结构体字段只读访问、enum 上下文、运算类型、完整返回路径、直接/间接递归、错误批量报告。模式覆盖嵌套对象和 struct 字段、范围、绑定、or 分支导出一致性、not 不导出变量、重复字段/绑定、参数冲突及 owner 祖先锚点。

新增 8 个语义测试（包含 20 余个非法函数体案例和多个非法模式案例），1 个 CLI 测试实际输入正确/错误函数并检查退出状态；总计 34 个测试。原始最终测试和 Clippy 输出分别归档为 body-tests.log、body-clippy.log。

当前限制：对象关系暂使用已声明的逻辑路径层次；尚无关系基数、生命周期或 accessor 元信息。对象身份绑定因缺少明确 handle 元信息而拒绝。没有跨包程序编译、标准输出接口、Plan IR、执行器、ABI 调用或 tt-emule 实测。函数体检查仅做静态类型和已支持语法的控制流分析，动态算术错误必须由后续执行器处理。
